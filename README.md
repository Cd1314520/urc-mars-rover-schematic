# UH URC Mars Rover – Electrical

Power subteam work for URC 2027. The folders follow the power tasks on the team Google Drive (`_2.2.3.2_Power_Architecture`).

## Task folders

| Folder | Drive task | Drive folder | Contents |
|---|---|---|---|
| [Task2_Old_Architecture_Power_Supply/](Task2_Old_Architecture_Power_Supply) | Task 2: power supply and battery for the old architecture | `_2.2.3.2.2_Old_Architecture_Power_Supply` | URC Task 2 Report (PDF). Excel workbooks stay out of Git |
| [Task2_Old_Architecture_Flowchart_Schematic/](Task2_Old_Architecture_Flowchart_Schematic) | Task 2: flowchart and schematic of the old architecture | `_2.2.3.2.3_Old_Architecture_Flowchart/Schematics` | KiCad project of the old architecture (lidar/navigation sheet, Ricky's old arm servo sheet) and its workflow rules ([README](Task2_Old_Architecture_Flowchart_Schematic/README.md)) |
| [Task4_2027_Architecture/](Task4_2027_Architecture) | Task 4: 2027 architecture subsystem schematics, plus cooling and physical layout (taken over from Hogan) | `_2.2.3.2.4_2027_Architecture` | Comms/Navi schematic plan, cooling plan, heat sink and harness research, physical layout and figures |
| [Task5_Protection_Wiring_Connectors/](Task5_Protection_Wiring_Connectors) | Task 5: protection, wiring and connector selection | `_2.2.3.2.4_2027_Architecture` (Power_Task_5.docx) | Comms/Navi branch protection table draft |
| [Integration/](Integration) | Integration of everybody's KiCad | `_2.2.3.2.7 Integration of everybody's KiCad` | One KiCad project with a sheet per subsystem. **Start with its [README](Integration/README.md)** to learn how to push your sheet |

No Task 1 or Task 3 folder: the Task 5 brief refers to a "Task 3 power budget", but no Task 1 or Task 3 files were found to put here. The closest Drive folder is `_2.2.3.2.3.1_New_Architecture_Power_Supply` (component loads, battery swap report).
